# This Could Be Your Site

A standalone Front of House showcase with six repeating restaurant website concepts. Built with Vite, TypeScript, and static content. No account, backend, analytics, or visitor data storage is required.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The static site is emitted to `dist/`. See `docs/content-model.md` to edit copy, images, and menu placeholders. See `docs/photo-sources.md` for the photograph source and CC0 record.

## Photography

The showcase uses real CC0 photographs from Wikimedia Commons. The site credits each photographer in its menu view and links to the source file page. No generated image is used in the published site.
