# This Could Be Your Site

A standalone Front of House showcase with three repeating restaurant website concepts. Built with Vite, TypeScript, and static content. No account, backend, analytics, or visitor data storage is required.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The static site is emitted to `dist/`. See `docs/content-model.md` to edit copy, images, and menu placeholders.

## Image prompts

The final WebP images in `public/images` were created with the built-in image generation tool and optimized for this project. The prompts were:

1. Editorial fine dining concept: intimate contemporary dining room at blue hour, linen table, plated seasonal dish, warm amber lighting, left-side negative space, realistic photography, no brands or text.
2. Vibrant counter service concept: freshly prepared sandwich and vegetables on a paper-lined counter, sunlight, saturated red and yellow accents, dynamic editorial food photography, no brands or text.
3. Neighborhood café concept: sunlit table with ceramic coffee, flaky pastry, warm linen, cocoa and cream tones, editorial film photography, no brands or text.
